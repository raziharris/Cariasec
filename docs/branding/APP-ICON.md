# Cariasec app icon

Final icon: five career characters (doctor, engineer, chef, teacher and artist), with the lowercase cariasec wordmark. Generated using the built-in imagegen tool; exported as opaque PNGs without pre-rounded corners.

Source: `cariasec-icon-source.png`. Production exports: `../../public/icons/cariasec-careers-{32,180,192,512,1024}.png`. Regenerate sizes with `scripts/export-app-icons.ps1`.

iPhone uses the 180px apple-touch-icon. The manifest and icon links remain scoped to the configured application base path. Existing Home Screen shortcuts may need to be added again to pick up the new artwork. Device installation has not been tested on a physical iPhone.

Platform reference: https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html
